# GenoScreen

**GenoScreen** is a student biomedical engineering project concept for exploring how HEXA gene variant information related to Tay-Sachs disease might be organized in a web interface.

> **Educational prototype only:** This repository's starter version does not diagnose Tay-Sachs disease, does not rule it out, does not query ClinVar, and does not run a trained machine-learning model. It must not be used for clinical decisions.

## Features

- Responsive HTML, CSS, and JavaScript interface
- Form fields for gene, variant notation, consequence, and source
- Educational summary of entered information
- Clear limitations notice and future-development ideas

## Files

- `index.html` — page structure and form
- `style.css` — layout, colors, and responsive styling
- `script.js` — form handling and educational summary
- `README.md` — project documentation

## Run locally

1. Download or clone this repository.
2. Keep all four files in the same folder.
3. Open `index.html` in a web browser.

No package installation is required for this starter version.

## Publish with GitHub Pages

1. Upload these files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to provide the published URL.

## Scientific and clinical limitations

This starter template only displays the information entered by the user. It does not establish whether a variant is pathogenic, calculate an individual's disease risk, or provide a diagnosis. Variant interpretation requires reliable evidence, correct transcript/reference information, and review by qualified professionals.

If a machine-learning model is added in a future version, document its dataset, inclusion criteria, labels, data split, validation method, metrics, limitations, and intended use. Do not describe a model as clinically validated unless appropriate evidence supports that claim.

## Privacy

Do not upload identifiable patient information, genetic records tied to an individual, passwords, API keys, or other confidential data to a public repository.
